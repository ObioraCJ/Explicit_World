# Explicit_World E-Commerce Web App

A full-stack e-commerce platform for a tailoring/fashion business, built with the MERN stack (MongoDB, Express, React, Node.js), styled with Tailwind CSS, and deployed via a Dockerized DevOps pipeline.

## Project Structure

- `server/` — Node.js + Express REST API
- `client/` — React (Vite) + Tailwind frontend

## Getting Started (Backend)

\`\`\`bash
cd server
npm install
cp .env.example .env   # then fill in real values
npm run dev
\`\`\`
